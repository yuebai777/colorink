# 常见问题

## 热键冲突与窗口救急

### 右键托盘图标打不开菜单 / 设置进不去了怎么办？

把鼠标右键绑定成全局热键（如「隐藏窗口」）后，在任务栏或托盘区域点击时，
Colorink 的置顶窗口可能盖住系统弹出的菜单。

- **首选**：设置 → 快捷键 → 勾选「排除任务栏与托盘区域」（默认开启）。
  开启后鼠标键热键在任务栏 / 托盘 / 系统菜单区域内不会触发，系统原生菜单正常弹出。
- **兜底热键**：无论怎么改绑，`Ctrl+Alt+Shift+,` 永远可以直接打开设置
  （硬编码、不可解绑）。所有入口都失联时用它。
- 托盘图标上**双击左键**：窗口已显示时直接进入设置。
- 仍无法解决：任务管理器结束 Colorink，然后 `Win+R` 输入 `%APPDATA%\Colorink`，
  编辑 `hotkey-config.json` 中的热键绑定（或把该文件重命名为 `.bak` 恢复默认）。
