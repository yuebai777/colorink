# 常见问题解答 (FAQ)

本页汇总了用户与画师在使用 Colorink 过程中最常遇到的疑问与排错方案。

---

## 1. 下载与运行问题

### Q: 首次运行时 Windows 提示“已保护你的电脑”怎么办？
**A**: 这是 Windows 对新发布的无签名独立开源软件的通用拦截提示（SmartScreen）。
- 点击提示框左侧的 **“更多信息”**；
- 随后右下方会出现 **“仍要运行”** 按钮，点击即可启动。
- Colorink 为 100% 开源项目，源码完全公开在 GitHub 上，不含任何恶意代码。

### Q: 杀毒软件（如 360 / 火绒 / Windows Defender）误报怎么办？
**A**: 单文件版打包（PyInstaller）在极少数情况下可能被部分杀毒软件误判。
- 建议将 `Colorink.exe` 或解压目录添加到杀毒软件的信任区 / 白名单；
- 或者下载使用 **`Colorink-Onedir.zip`（便携目录版）**，由于依赖文件均为独立的明文 `.pyd` 与 `.dll`，误报率显著更低。

## 2. 软件同步与画画问题

### Q: 在 Colorink 里取色了，但画画软件里的颜色没有变？
请按以下清单进行快速排查：
1. **画布是否打开**：无论是 PS、CSP 还是 SAI 2，在软件刚启动、尚未新建或打开任何图纸画布时，绘画软件的画笔色彩引擎是不接收外部输入的。请先**新建一张画布**测试；
2. **连接状态是否为绿色**：进入 Colorink 的 **设置 → 同步**，确认当前显示的是绿色的 **“已连接”** 状态；
3. **CSP 推荐 Companion 模式**：如果你使用的是 CSP 5.1+，请勿使用 Memory 内存模式，改用 Companion 扫码模式；
4. **权限是否对齐**：如果你曾以“管理员身份运行”打开了画画软件，Windows 会阻止普通权限程序向其发送数据。请将 Colorink 和画画软件都以普通用户权限运行（或都以管理员身份运行）。

## 3. 灰度滤镜问题

### Q: 按 `Ctrl + Alt + D` 灰度滤镜没有反应，或提示不支持？
**A**:
- 默认的 **Native 感知灰度** 后端基于 DXGI 屏幕采集与 OpenGL 3.3+ 硬件加速。如果你的电脑是老旧核显、显卡驱动受损、或处于远程桌面/虚拟机环境中，OpenGL 可能无法初始化；
- **解决办法**：进入 Colorink 的 **设置 → 灰度**，将后端切换为 **Mag（Windows 放大镜模式）**。Mag 模式使用系统自带的显示变换通道，完全不依赖独立显卡与 OpenGL，兼容性最强。

---

## 4. 数位板与压感笔体验

### Q: 用数位板笔点击色盘上的调和副点时，容易不小心晃动锚点？
**A**:
- Colorink 针对压感笔内置了 **5 像素防抖阈值**：笔尖接触屏幕产生 5px 以内的微小晃动一律视为点选而非拖拽；
- 同时，Colorink 优化了 Windows Ink 与 Wintab 驱动的光标映射，悬停时会自动同步十字准星光标。

---

## 5. 开机自启动与系统设置

### Q: 开启开机自启需要管理员权限吗？
**A**: 不需要。Colorink 的开机自启动写在当前用户的注册表项中（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`），完全不需要 UAC 管理员弹窗，绿色环保，随时可在 **设置 → 常规** 中开启或关闭。

## 6. 反馈 Bug 与复制诊断信息

如果你遇到了意料之外的报错、崩溃或同步异常，可以通过以下方式提交给作者：

1. 打开 Colorink，进入 **设置** 界面；
2. 找到并点击 **【复制诊断信息】** 按钮；
3. Colorink 会将当前版本、操作系统环境、已连接的绘画软件状态以及最近的日志信息复制到剪贴板；
4. 前往 **[GitHub Issues](https://github.com/yuebai777/colorink/issues)** 提交反馈，或直接在官方 QQ 交流群（群号：**1108560464**）中粘贴发送给作者。
