# 常见问题解答 (FAQ) 与故障排查

本页汇总了画师与设计师在使用 Colorink 过程中最常遇到的疑问与排错方案。

---

## 1. 下载与运行

### Q: 首次运行时 Windows 提示“已保护你的电脑”怎么办？
**A**: 这是 Windows 系统对未购买昂贵商业签名的独立开源软件的通用拦截提示（SmartScreen）。
- 点击提示框左侧的 **“更多信息”**；
- 随后右下方将出现 **“仍要运行”** 按钮，点击即可启动。
- Colorink 源码 100% 公开于 GitHub，绝不含任何恶意代码。

### Q: 杀毒软件（如 360 / 火绒 / Windows Defender）误报怎么办？
**A**: 单文件版打包（PyInstaller）在极少数情况下可能被部分杀毒软件误判。
- 建议将 `Colorink.exe` 添加到杀毒软件的信任区 / 白名单；
- 或者下载使用 **`Colorink-Onedir.zip`（便携目录版）**，由于所有依赖均为独立的明文动态链接库，几乎不会被误报。

## 2. 绘画软件色彩同步排错

### Q: 在 Colorink 里取色了，但画画软件里的画笔颜色没有变？
请按照以下步骤依次检查：
1. **画布是否打开（最常见原因）**：无论 PS、CSP 还是 SAI 2，在软件刚启动、尚未新建或打开任何图纸画布时，绘画软件的内部画笔色彩引擎是不接收外部输入的。**请先新建一张画布测试**；
2. **连接状态灯是否为绿色**：打开 Colorink 的 **设置 → 同步**，查看底部的状态指示灯是否显示为绿色的 **“已连接”**；
3. **CSP 用户务必确认连接模式**：如果你使用的是 CSP 5.1 或更高版本，请勿使用 Memory 内存模式（5.1 官方重构已不支持），必须使用 **Companion 手机扫码模式**；
4. **管理员权限是否一致**：如果你曾右键以“管理员身份运行”打开了画画软件，Windows 会阻止普通权限程序向其发送数据。请将两者统一（都以普通模式运行，或都以管理员模式运行）。

## 3. 取色视窗与手势技巧

### Q: 取色时怎么看清动态画面或细小像素？
**A**:
- **动态画面**：按住 **`Alt`** 键可临时定格采样画面；
- **放大细节**：滚动**鼠标滚轮**可在 2× ~ 20× 之间无级放大；
- **直线色卡采样**：按住 **`Shift`** 键可自动锁定水平或垂直线，防止鼠标手抖偏离。

## 4. 灰度滤镜检查

### Q: 按 `Ctrl + Alt + D` 灰度滤镜没有反应，或提示不支持？
**A**:
- 默认的 **DComp** 与 **Native** 模式依赖现代显卡硬件加速。如果你使用的是老旧集成显卡或虚拟机环境，可能无法初始化；
- **解决办法**：进入 Colorink 的 **设置 → 灰度**，将运行模式切换为 **Mag（Windows 系统放大镜模式）**。Mag 模式使用系统内核级色彩矩阵，完全不依赖独立显卡，兼容性最强。

### Q: 双屏画师如何只让画画的数位屏变黑白，参考屏保持彩色？
**A**:
- 进入 **设置 → 灰度**，在 **灰度作用屏幕** 下拉菜单中，选择你的**数位绘图屏**（如 `1: DISPLAY2`）；
- 这样按下快捷键时，只有画画的屏幕会变黑白供你检查素描关系，旁边的参考图屏幕依然保持全彩看色。

## 5. 工作流与数位板压感笔体验

### Q: 调色时不希望抢走绘画软件的键盘焦点？
**A**:
- 进入 **设置 → 界面**，勾选 **【无焦点模式 (No Focus Mode)】**；
- 开启后，在 Colorink 窗口上调色、拖动滑块均不会抢夺当前画画软件的键盘焦点。

### Q: 用数位板笔点击色盘上的调和点时，容易不小心误拖动？
**A**:
- Colorink 内置了 **5 像素微动防抖算法**：数位板笔尖接触屏幕产生 5px 以内的轻微抖动一律视为点选而非拖拽，避免误晃锚点。

### Q: 如何让 Colorink 的窗口外观完美融入我的绘画软件？
**A**:
- 进入 **设置 → 界面 → 界面主题**，选择 **“屏幕取色”**；
- 点击 **【设定】**，窗口隐藏 3 秒，把光标移到你的 CSP 或 PS 界面底色上吸色，Colorink 就会自动变身专属皮肤！

## 6. 反馈 Bug 与复制诊断信息

遇到异常报错、崩溃或同步断开时，可以通过一键诊断快速反馈给作者：

1. 打开 Colorink，进入 **设置 → 同步**；
2. 找到并点击底部的 **【复制诊断信息】** 按钮；
3. Colorink 会把当前软件版本、系统环境、前台进程状态以及详细报错日志自动复制到剪贴板；
4. 前往 **[GitHub Issues](https://github.com/yuebai777/colorink/issues)** 提交反馈，或直接在官方 QQ 交流群（**1108560464**）中粘贴发送给作者。
