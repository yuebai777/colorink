# 灰度滤镜与明度检查

本节介绍如何使用全局黑白灰度滤镜，在绘画过程中随时检查画面的明度层次与素描黑白灰关系。

---

## 1. 快捷键使用

- **开启 / 关闭**：按下全局快捷键 **`Ctrl + Alt + D`**（可在设置中修改）；
- **即开即关**：按一次屏幕变黑白，再按一次立即恢复全彩；
- **边看边画**：黑白滤镜开启时，所有数位板压感、快捷键和画笔操作完全正常，可以直接在黑白状态下调明度下笔。

---

## 2. 画画中的实用技巧

- **检查画面骨架**：剥离色彩的视觉干扰，一眼看出主体与背景拉没拉开、暗部是否过死、亮部是否过曝；
- **多显示器独立设置**：
  - 如果你有两台显示器（例如一台屏放参考图，一台数位屏画画）；
  - 进入 **设置 → 灰度**，可将作用范围指定为你的**数位绘图屏**；
  - 这样快捷键生效时，只有画画的屏幕变黑白，参考图依然保持彩色，对照十分方便。

---

## 3. 两种模式的选择

进入 **设置 → 灰度**，可选择滤镜运行模式：

- **Native（默认推荐）**：支持人眼感知灰度，支持指定单台显示器生效，切换平滑无闪烁；
- **Mag（备用系统模式）**：如果你的电脑显卡较老，或开启 Native 模式出现提示不支持，可在此处切换为 Mag 模式。
