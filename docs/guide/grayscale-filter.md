# 硬件级灰度滤镜与明度检查

在色彩插画与概念设计中，**画面的明度层级（Value / Luminance，即素描黑白灰关系）决定了作品的体积感、立体结构与视线引导**。

Colorink 内置了硬件级一键全局灰度滤镜，无需画师在绘画软件内部手动创建黑白调试图层，按下一个快捷键即可瞬间把屏幕切换为科学黑白视图。

---

## 1. 快捷键开启与关闭

- **切换快捷键**：按下全局热键 **`Ctrl + Alt + D`**（可在设置中自定义）；
- **即开即关**：按一次整个屏幕（或指定屏幕）立即变为黑白灰度；再次按下即刻无损恢复全彩；
- **支持在黑白状态下直接作画**：灰度滤镜完全不会拦截鼠标、数位板压感笔与绘画软件输入，画师可以在黑白视图下直接微调画笔下笔。

---

## 2. 为什么画师必备全局灰度检查？

1. **快速排查主体与背景对比**：当画面颜色较多时，肉眼极易受色相与纯度迷惑。开启灰度能瞬间看清人物主体是否与背景糊成一团、阴影层次是否太死、高光是否过曝；
2. **跨软件对照参考图**：网页参考、纯色色板、3D 辅助图和画布同时变灰，方便横向比对真实素描明度；
3. **彻底杜绝“忘记删黑白层”**：传统的画法是在 CSP 或 PS 顶部建一个黑白调整图层，经常在交稿、导出或合层时忘记隐藏；全局滤镜完全不写入图层文件，零文件污染。

---

## 3. 科学明度色彩模式：OKLCh vs Luma

进入 **设置 → 灰度 → 灰度模式**，你可以选择不同的明度数学模型：

| 模式名称 | 数学原理 | 特点与适用场景 |
| :--- | :--- | :--- |
| **OKLCh 感知均匀（强烈推荐）** | 基于最新 OKLCh 色彩感知科学 | **贴合人眼真实视觉**。人眼对黄色极为敏感、对深蓝敏感度低。传统去色容易把纯黄变灰，OKLCh 能准确呈现黄色是亮灰、蓝色是深黑的真实素描明度。 |
| **Luma (BT.709 标准)** | 国际电视与视频标准（`0.2126 R + 0.7152 G + 0.0722 B`） | 广播影视级亮度标准，适合影视概念设计、动画分镜背景的灰阶对照。 |

---

## 4. 底层渲染后端说明

可在 **设置 → 灰度 → 运行模式** 中选择后端：

- **DComp (DirectComposition，默认推荐 ⭐⭐⭐⭐⭐)**：采用现代 Windows 显存直通零拷贝架构，延迟低于 1ms，性能损耗几乎为零，**完美支持 OKLCh 感知灰度** 与多显示器独立指定；
- **Native (DXGI + OpenGL，优质备选 ⭐⭐⭐⭐)**：采用 DXGI 桌面捕捉与 OpenGL 硬件加速，**同样完整支持 OKLCh 感知灰度** 与单显示器指定。当 DComp 模式在特殊多显卡环境或显卡驱动下未正常激活时，建议优先切换为 Native 模式；
- **Mag (Windows 系统放大镜)**：系统级内核颜色矩阵变换。
  > [!WARNING] 注意：Mag 模式无法开启 OKLCh
  > Mag 模式受限于 Windows 系统的底层 API，**无法支持 OKLCh 感知灰度（仅支持传统的线性 Luma），且无法指定单个屏幕**。因此若想使用科学的 OKLCh 感知明度检查素描关系，请务必保持使用 **DComp** 或 **Native** 模式。

---

## 5. 多显示器画师专属配置技巧

如果你使用双屏（例如一台主屏看参考图，一台数位绘图屏画画）：

1. 打开 **设置 → 界面 / 快捷键 → 灰度作用屏幕**；
2. 下拉菜单会自动列出当前电脑连接的所有显示器（如 `0: DISPLAY1`、`1: DISPLAY2`）；
3. **选中你的数位绘图屏**；
4. 此时按下 `Ctrl + Alt + D`，**只有画画的屏幕会变黑白，旁边的参考图屏幕依然保持全彩**！对照画画极其高效。
