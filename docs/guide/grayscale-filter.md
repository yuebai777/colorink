# 灰度滤镜与明度检查

在色彩插画、原画设计与厚涂创作中，**“素描关系”（即画面的黑白明度 Value / Luminance）决定了画面的骨架与立体感**。如果明度层次不清晰，再艳丽的色彩也容易显得画面灰暗、混乱或平淡。

Colorink 内置了硬件级的一键全局灰度滤镜，无需画师在 CSP / PS 里层层建立黑白调整图层，直接按一个快捷键即可瞬间把整个屏幕切换为黑白视图！

---

## 1. 快捷开启与关闭

按下全局快捷键 **`Ctrl + Alt + D`**（可在设置中修改）：
- **瞬间切换**：整个屏幕（或你指定的某台画画屏）立即变为黑白灰度；
- **随时还原**：再次按下 `Ctrl + Alt + D`，即刻恢复全彩显示；
- **在黑白模式下继续作画**：滤镜只是系统级覆盖显示，完全不影响你的数位板压感、绘画软件笔刷与正常操作。

---

## 2. 为什么比普通画图软件内置的黑白图层更好？

1. **跨软件全局生效**：你的参考图、网页参考、3D 辅助模型和画布全部同步变灰，能直接把参考素材与自己画布上的黑白对比度并排对比；
2. **零文件污染**：画完不用专门去删掉或者隐藏黑白调试图层，彻底避免导出交稿时“忘记删黑白层”的尴尬；
3. **真实感知明度算法**：普通画画软件如果使用简单的“去饱和度”，黄色的明度和蓝色的明度计算可能严重失真。Colorink 提供了符合人眼感知曲线的科学模型。

---

## 3. 双后端机制：Native 与 Mag

进入 **设置 → 灰度**，Colorink 提供了两种底层渲染后端：

| 后端模式 | 核心技术 | 算法支持 | 核心优势 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **Native（默认推荐）** | DXGI 桌面复制 + OpenGL 硬件加速 | **OKLCh 感知灰度** & **BT.709 Luma** | 贴合人眼感知明度、**可指定单台显示器生效**、启动后台预热、无切换闪烁 | 独立显卡电脑、双屏画师（仅让数位屏变黑白，主屏保留色彩看参考） |
| **Mag（备用）** | Windows 放大镜系统 API | **BT.709 Luma** | 零捕获、零覆盖窗口、完全不占额外 GPU 显存，兼容性极高 | 无法开启 OpenGL 的集成显卡、老电脑或虚拟桌面 |

> [!TIP] 多显示器画师推荐用法
> 如果你平时使用“一台电脑屏幕放参考图，一台数位屏/数位板画画”，进入 **设置 → 灰度**，将作用屏幕指定为你的 **数位绘图屏**。
> 这样按下快捷键时，只有画画的屏幕会变成黑白供你检查明度，旁边的参考图屏幕依然保持全彩，对照非常直观！
