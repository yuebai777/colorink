# 自由面板、悬浮布局与界面定制指南

Colorink 拥有极高自由度的桌面布局系统，从**模块拖拽重排**、**多面板页签（Tabs）折叠**、**双击拆卸为独立浮窗**，到**0%~100% 背景半透明悬浮**与**吸管定制软件皮肤**，全面适配画师的个性化工作流。

---

## 1. 模块化自由面板系统

Colorink 的所有滑块组（RGB、HSV、VHSV、HSL、LAB、OKLab、OKLCh）以及取色历史面板均由模块化面板宿主驱动。

### 面板拖拽重排
1. 打开 **设置 → 面板**，勾选 **【开启面板抓手】**；
2. 主界面每个模块顶部会出现一条轻量抓手栏；
3. 鼠标按住抓手上下拖拽，即可随心所欲调整各滑块组与历史色板的显示顺序。

### 页签折叠（Tabs 模式）
如果你的屏幕垂直空间紧张，希望节省高度：
1. 在 **设置 → 面板** 中勾选 **【滑块组分页签叠放】**；
2. 各个色彩空间的滑块组将自动折叠为顶部的标签页（Tabs）；
3. **智能防跳页保护**：在切换颜色或打开设置时，Colorink 会精准记忆你当前正在使用的标签页，不会发生意外跳回默认页的情况。

### 双击拆卸为独立浮动窗口（Floating Panels）
如果你想把“取色历史”或某个滑块面板单独挂在副屏、或放在画布旁边：
- **拆卸为独立浮窗**：**直接双击**任意面板的抓手条，该模块立刻飞出成为独立的置顶小工具窗；
- **拖到窗口外也是浮出**：按住抓手拖到任何窗口之外松手，同样成为独立浮窗；拖动时鼠标下方会跟着一块该面板的缩略条，落点提示画在主窗口或目标浮窗里；
- **浮窗之间互拖**：把一个浮窗拖到另一个浮窗上松手，面板会并进那个窗口（页签模式下落在中间即叠成页签）；
- **8 向自由缩放**：把鼠标移到浮动窗口的四边或四角，支持 8 个方向随意拉伸调整尺寸；
- **置顶图钉（Pin）**：浮窗标题栏右上角带有一枚图钉按钮，点击可切换是否始终置顶显示；
- **一键精准收回**：**双击浮动窗口标题栏**，或者点击右上角的 **收回（×）** 按钮，该面板就会毫秒级回到主窗口的原槽位；
- **重启记忆**：即使关闭软件再重新打开，所有浮动面板的位置与尺寸都会被完整记忆还原；**手动拉伸过的浮窗会保持你拉的那个尺寸**（不会在下次启动时被自动缩回内容高度）。

## 2. 画布半透明悬浮（画师核心特性）

很多画师习惯把色盘直接悬浮在画布的线稿或铺色区域上方作画。传统的黑色实心窗口会严重遮挡画面内容。

### 0% ~ 100% 背景无级半透明调节
进入 **设置 → 界面 → 背景不透明度**：
- **无级拖动滑块**：窗口底色、边框与标题栏的透明度会实时跟随滑块改变；
- **极限 0% 完全隐形**：调至 0% 时，窗口的背景底板完全隐形，只剩下色相环、滑块轨道与色块悬浮在你的绘画画布之上；
- **纯净采色不被底层污染**：请放心，色彩滑块、色轮与色格本身始终保持 100% 不透明，取色绝对纯正；
- **透明区域依然可拖动**：即使背景完全透明，在透明底板处按住鼠标依然可以自由拖动窗口移动，点击不会意外穿透到下层画布。

## 3. 极简无边框悬浮与工作流辅助

- **显示/隐藏标题栏**：按下全局快捷键 **`Ctrl + Alt + K`**，一键隐去主窗口顶部的标题栏与边框，只留色盘和滑块；
- **跟随鼠标快捷键**：按下 **`Ctrl + Alt + J`**，窗口自动瞬移到当前鼠标位置；
- **无焦点模式（No Focus Mode）**：进入 **设置 → 界面** 开启。开启后，在 Colorink 窗口上调色、拖滑块完全不抢夺外部绘图软件的键盘焦点，快捷键无需重新激活；
- **锁定窗口大小与位置**：在设置中开启“锁定窗口大小”或“锁定窗口位置”，防止数位板运笔时不小心拖动窗口边缘导致形变。

## 4. 界面主题与“吸管定制皮肤”

Colorink 支持多种边框与滑块风格，更支持直接用吸管吸取你喜爱的画画软件的主题色：

1. 打开 **设置 → 界面 → 界面主题**；
2. 下拉菜单支持：
   - **自动匹配**：自动跟随当前绘画软件；
   - **深灰 / 纯白 / 纯黑**：经典固定主题；
   - **屏幕取色（Eyedropper 专属定制）**：
     - 选择“屏幕取色”后，下方会出现 **控制栏** 与 **背景** 两个吸管取色项；
     - 点击 **【设定】**，Colorink 窗口会自动隐藏 3 秒钟；
     - 在这 3 秒内，你只需把鼠标悬停在你的 Photoshop、CSP 或 SAI2 的界面底色上；
     - 3 秒倒计时结束后，Colorink 会自动采样该位置色彩，将整个工具的皮肤完美融入你的绘画软件！
