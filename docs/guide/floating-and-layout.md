# 自由面板与悬浮布局

为了适应不同的绘画工作区（如单屏画板寸土寸金、双屏搭配、以及将调色盘挂在画布旁边的场景），Colorink 提供了极高自由度的面板定制系统与半透明悬浮机制。

---

## 1. 模块化自由面板系统

### 面板拖拽与重排
在主窗口点击面板抓手（或进入 **设置 → 界面** 开启面板抓手），各个模块（如 HSV 滑块组、RGB 滑块组、取色历史面板）均可自由拖拽位置。你可以按自己的习惯上下调换顺序。

### 页签叠放（Tabs）
如果垂直屏幕空间有限，你可以将多个滑块面板**叠放为标签页（Tabs）**：
- 拖拽面板到另一个面板的标签栏上即可完成合并；
- **智能防跳页记忆**：当你在不同色彩模式之间切换、或重启软件时，Colorink 会自动记住你当前停留的标签页，绝不发生意外跳页。

### 独立浮动窗口（Floating Panels）
某些模块（例如“取色历史”或“调色滑块”）你可能想单独放到屏幕另一个角落或副屏上：
- **拖出为独立窗口**：按住抓手拖出主窗口范围，或者**直接双击抓手**，面板就会立即化身为主窗口外部的独立置顶小工具窗；
- **8 向自由拉伸**：浮动窗口边缘支持 8 个方向随意缩放拉伸尺寸；
- **一键复位还原**：双击浮动窗口的标题栏，或者点击窗口右上角的“收回”按钮，它就会精准复位回原来的槽位；软件重启后也会完整记住浮动状态。

---

## 2. 半透明背景悬浮（画师力荐特性）

很多画师习惯一边看着画布的局部阴影，一边在旁边挑色。如果调色器底色太黑太厚重，会遮挡线稿和画面。

### 0% ~ 100% 无级背景透明度
进入 **设置 → 界面 → 背景不透明度**：
- **无级滑条调节**：窗口底色、外框和标题栏会随着滑块实时变透；
- **极限 0% 完全隐形**：当调到 0% 时，窗口本身的背景完全透明消失，只留下色相环、滑块轨道和颜色方块悬浮在你的绘画软件画布上方；
- **纯净取色不受底色干扰**：请放心，色彩滑块、色盘手柄和色块本身始终保持 100% 不透明，绝对不会被底下的画布混色，确保你取出的颜色数值绝对纯净精确。

---

## 3. 极简无边框模式

- **隐藏标题栏快捷键**：按下 `Ctrl + Alt + K`，主窗口顶部的标题栏与边框瞬间隐去，最大化节省画面占用空间；
- **贴边跟随**：搭配 `Ctrl + Alt + J`，可以在绘画时随手把 Colorink 唤到画笔旁，选好颜色后固定，提升创作专注度；
- **Ringless 极简切片模式**：如果你平时只依赖滑块或只想要一个极窄的颜色条，可以在设置中开启该模式，色相环自动隐藏，主色块放大并紧凑贴边。
