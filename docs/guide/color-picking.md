# 全局取色与放大镜

本节介绍如何使用全局放大镜在屏幕任意位置快速取色，以及管理取色历史面板。

---

## 1. 放大镜取色步骤

1. **呼出放大镜**：按下全局快捷键 **`Ctrl + Alt + Q`**（可在设置中修改）；
2. **移动准星选色**：屏幕会冻结并显示像素放大网格，光标右下方实时显示当前像素的十六进制颜色码（HEX）；
3. **点击确认取色**：
   - **鼠标左键点击**：确认拾取当前十字准星所在的像素颜色，Colorink 会立即更新前景色并同步给绘画软件；
   - **取消退出**：如果不打算取色，按下键盘 **`Esc`** 键或点击鼠标右键，即可退出放大镜模式，不改变当前颜色。

> [!TIP] 多显示器与高分屏
> 放大镜支持跨屏移动，光标移动到任意显示器（无论是 4K 屏、带缩放的高分屏还是竖屏）均可直接点击取色，会自动对齐原生物理像素。

---

## 2. 取色历史面板的使用

主窗口下方的色块网格会自动记录你的选色足迹：

- **重新选用**：直接点击历史面板里的任意色块，即可将该颜色重新设置为当前前景色；
- **自动去重与置顶**：当再次使用相同的颜色时，该色格会自动前移到第一个位置；
- **外部同步记录**：在外部绘画软件（如 Photoshop / CSP）中吸取的颜色也会自动同步记录到历史面板；
- **调整色格尺寸**：进入 **设置 → 界面**，可以自由调节历史网格的显示行数、列数以及色块尺寸大小。
