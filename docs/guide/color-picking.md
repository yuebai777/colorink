# 全局取色与放大镜操作指南

Colorink 搭载了高精度的全屏取色放大镜与历史色板系统。本文详细讲解取色视窗的全部手势快捷键、采样细节与历史面板管理。

---

## 1. 呼出全屏放大镜

按下全局快捷键 **`Ctrl + Alt + Q`**（可在设置中自定义）：
- 屏幕将即时定格，光标周围弹出高精度放大网格；
- 放大镜面板自动避开鼠标落点，并在右下方实时显示当前像素的 **HEX 十六进制色码**、**RGB 数值** 与 **当前倍率**；
- **免窗口自身干扰**：Colorink 会在截图瞬间完成离屏抓取，画面中绝不会截入 Colorink 窗口自身、放大镜或光标阴影。

---

## 2. 取色视窗核心快捷操作（必看技巧）

在放大镜激活状态下，你可以使用以下组合键与手势进行高精度控制：

| 快捷按键 / 手势 | 操作功能 | 详细说明与使用场景 |
| :--- | :--- | :--- |
| **`Alt`（按住）** | **临时冻结画面** | 冻结当前的采样画面。适用于捕捉视频帧、动态网页、动效演变或易消失的悬停色彩。再次松开即恢复跟随。 |
| **鼠标滚轮** | **调节放大倍率** | 上下滚动滚轮，可在 **2× ~ 20×** 之间实时缩放放大镜网格，看清细微描边或单个像素点。 |
| **`Shift`（按住）** | **锁定水平 / 垂直轴** | 按住 Shift 后轻移鼠标，自动锁定为**纯水平**或**纯垂直**采样轴。在多色渐变条或直线色板上吸色时，可防止手抖偏离基准线。 |
| **`Space`（空格按住）** | **临时隐藏准星** | 临时隐去中心十字准星与准星指示点，直接观察中心像素的原貌，松开立即重新显示。 |
| **鼠标左键** | **确认取色** | 确认拾取当前中心十字准星所在的像素颜色，Colorink 会立刻更新前景色并瞬时同步给绘图软件。 |
| **鼠标右键 / `Esc`** | **取消退出** | 放弃本次取色并退出放大镜，不改变当前选定的颜色。 |

> [!TIP] 多显示器与高分屏无缝漫游
> 放大镜支持跨屏幕随意移动。无论你的电脑连接了多少台显示器、各屏幕的分辨率与 Windows 缩放比例（DPR 如 100%、125%、150%、200%）是否一致，Colorink 均会根据当前光标所在的物理屏幕精准采集原生像素数据。

## 3. 取色历史面板的使用与管理

主窗口下方的色块网格会自动记录你的每一次色彩采集：

### 基础交互
- **重新选用**：左键单击历史色板中的任意色格，该颜色立刻被激活为当前工作色；
- **右键复制色码**：在任意色格上**右键点击**，可呼出菜单快速复制：
  - **Copy RGB**：复制为 `rgb(r, g, b)` 格式；
  - **Copy HEX**：复制为 `#RRGGBB` 十六进制色码；
- **自动去重与置顶**：当调配或吸取了历史上已存在的颜色时，该色块会自动晋升到第一格，不会重复堆叠无用色块；
- **双向联动录入**：在连接了外部绘画软件（如 Photoshop / CSP）时，你在绘画软件内部用吸管吸取的颜色也会自动同步录入到 Colorink 的历史面板。

### 自定义色板网格布局
进入 **设置 → 取色器**，你可以自由设定历史面板的外观规格：
- **列数（Columns）**：支持 4 ~ 16 列自定义排布；
- **行数（Rows）**：支持 1 ~ 8 行自定义；
- **色块尺寸（Swatch Size）**：可根据你的屏幕大小与窗口宽度自由调整色格的像素宽高。
