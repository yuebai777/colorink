# 全局取色与放大镜

对于插画与设计工作流，准确而高效地拾取参考图或屏幕上的色彩至关重要。Colorink 针对高分屏、色彩真实度和落笔延迟做了专门的底层优化。

---

## 1. 呼出全屏放大镜取色

按下全局快捷键 `Ctrl + Alt + Q`（可在设置中更改）：

1. **屏幕冻结放大**：光标周围会立即出现高精度的全屏放大镜网格，将像素细节放大展示；
2. **免自身干扰**：Colorink 会在截图前智能隐藏或离屏抓取，放大镜中绝对不会把软件窗口自身或残留的光标截进去；
3. **高分屏与多显示器自适应**：无论你是 4K 200% 缩放主屏搭配 1080P 副屏，还是横竖屏混用，Colorink 都能根据光标所在显示器的原生物理像素与设备像素比（DPR）精准对齐。

---

## 2. 精细像素采样

传统的取色工具经常简单地抓取一个模糊区块或者取色框中心点的平均值，导致在描边边缘或细线处取色偏灰偏淡。

- **点击点精确采样**：Colorink 采样的是你鼠标/数位板落笔点击瞬间的**原始像素**，完整保留底层真实色彩数据；
- **RGB 与十六进制 HEX 实时预览**：放大镜右下角实时显示当前十字准星悬停的十六进制色码与色彩预览。

---

## 3. 瞬时落笔机制（解决画画软件第一笔不同步的痛点）

在很多画师使用外部色轮取色时，常遇到一个普遍痛点：
> *“在取色器上刚点了一个新颜色，立即在 CSP / PS 画布上下笔，结果第一笔画出来的居然还是上一个旧颜色！”*

**Colorink 的底层解决机制**：
- 取色完成后，瞬间唤醒后台独立同步管道，进行非阻塞立即刷新（Flush）；
- 将同步延迟降至仅约 **5.5ms ~ 7.5ms**（以 CSP Companion 协议为例）；
- 即使画师点击取色后以极快的手速连击画板，画出的第一笔也必定是最新取到的颜色。

---

## 4. 取色历史面板

主界面下方的**取色历史**会自动记录你拾取或调制的色彩：

- **自动持久化**：关闭并重新打开软件后，所有历史色板依然完整保留；
- **智能去重与置顶**：当再次拾取或调入相同颜色时，该颜色会自动移动到历史列表第一位，不会在面板里产生大量重复杂乱色块；
- **双向联动录入**：不仅屏幕取色会记录，外部绘画软件（如 Photoshop / CSP）主动传来的颜色也会被纳入历史；
- **自定义网格**：进入 **设置 → 界面**，你可以自由设定历史色板的行数、列数以及色块尺寸大小，适配不同的窗口宽度。
