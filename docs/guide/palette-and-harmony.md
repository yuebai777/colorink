# 色盘与调和配色

本节介绍如何在常规色相环与 LAB 色盘之间切换，以及如何使用调和配色模式快速构建和谐的画面色彩。

---

## 1. 切换色环与 LAB 色盘

Colorink 提供了标准色相环与 LAB 环形色盘两种视图：

- **悬停快捷键（最方便）**：将鼠标光标移动到色盘上方，按下键盘 **`Space`（空格键）**，即可在色环与 LAB 色盘之间切换；
- **全局快捷键**：在任意位置按下 **`Ctrl + Alt + L`**；
- **界面按钮**：点击色盘与色槽之间的视图切换图标；
- **圆形与方形切换**：可在设置中切换圆形色盘（Disc）或方形色块（Square）。

---

## 2. 调和配色模式（Harmony）

在色盘界面开启调和配色后，色盘上会根据当前基准色自动计算出一组和谐的辅助色点：

| 配色模式 | 说明与建议用法 |
| :--- | :--- |
| **互补色 (Complementary)** | 两端 180° 对角色彩，用于强烈冷暖对比或视觉焦点提亮。 |
| **补色分割 (Split-Complementary)** | 基准色加上互补色两侧相邻的两个颜色（Y 形），层次更柔和。 |
| **类似色 (Analogous)** | 色环上相邻的邻近色，色彩温润统一，适合营造同色调氛围。 |
| **三色调和 (Triadic)** | 等边三角形 120° 三色组合，色彩丰富且平衡。 |
| **矩形 (Rectangle)** | 90° 四色方阵，适合多角色插画或复杂场景配色。 |

---

## 3. 调和锚点操作方式

- **点击副点选色**：直接用鼠标或数位板笔点击色盘上的任意副调和点，即可将该颜色设为当前前景色；
- **拖动主锚点**：拖拽主色锚点时，所有调和副点会严密保持几何角度联动跟随；
- **拖动副锚点**：拖拽副调和点时，整个调和骨架会联动旋转与缩放；
- **压感笔点选保护**：内置 5 像素微动防抖，使用数位板笔点按色点时不会因为笔尖微晃而误触发拖拽。
