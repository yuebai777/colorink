# 色盘与调和配色

Colorink 不仅是一个取色器，更是一套深度的色彩调和与探索工具。它内置了专为数字绘画打造的 **LAB 环形色盘** 以及源自经典色彩理论的 **五大调和配色体系**。

---

## 1. 色环与 LAB 色盘双视图

在传统 HSV 色相环之外，Colorink 提供了符合人眼视觉感知特性的 **LAB 环形色盘**。

### 快捷切换方式
- **局部快速切换（推荐）**：鼠标光标移动到色轮或色盘区域，按下键盘 **`Space`（空格键）**，即可瞬间在常规色相环与 LAB 色盘之间无缝切换；
- **全局快捷键**：在任意位置按下 **`Ctrl + Alt + L`**；
- **界面按钮**：在色轮与双色槽之间，点击浮动的切换按钮即可。

### 环形色盘特色
- **纯几何圆形遮罩**：彻底消除了传统 LAB 取色器在边缘容易出现的齿状缺口与凹凸不平，与外层色相环严格同心同径；
- **多线程预计算与高速查表**：拖动滑块或缩放色盘时，后台线程高精度查表加速，无论多高帧率下都保持丝滑顺畅；
- **圆形（Disc）与方形（Square）切换**：你可以在圆形色盘与方形色块之间自由选择喜欢的排布习惯。

---

## 2. 五大调和配色模式（Harmony）

想要让画面色彩统一又有张力？Colorink 提供了主流绘图工具（如 Procreate）广泛采用的和弦调和配色方案：

| 配色模式 | 特点与适用场景 |
| :--- | :--- |
| **互补色 (Complementary)** | 180° 对角线两端色彩，视觉冲击力强，常用于画面焦点提亮、冷暖对比拉扯。 |
| **补色分割 (Split-Complementary)** | 由基准色和互补色两侧相邻的两个颜色组成（Y 形），对比强烈但比单一互补色更柔和丰富。 |
| **类似色 (Analogous)** | 位于色环上相邻约 30°~60° 区间内的颜色，色彩和谐温润，适用于营造特定氛围或单一情绪调性。 |
| **三色调和 (Triadic)** | 色相环上相隔 120° 的三个等边三角形顶点色彩，色彩丰富平衡且生动。 |
| **矩形/四色 (Rectangle)** | 90° 正方形/矩形方阵组合，提供两组互补色对，适合层次复杂、元素众多的多角色插画设计。 |

## 3. 数位板笔交互与智能联动

针对板绘/屏绘用户的真实操作习惯，调和色盘做了大量精细的手感打磨：

### 1. 点击副点快速选色
调和模式展开后，色盘上除了你的主取色点外，还会显示对应的副调和色锚点。**你可以直接用笔或鼠标点击任意一个副点**，该点代表的色彩会立即被选为当前前景色并同步给画图软件。

### 2. 锚点拖拽与整组骨架联动
- 拖拽主锚点时，所有调和副点按几何关系严密跟随；
- 拖拽副锚点时，Colorink 通过逆向变换动态反解主锚点，实现**整组骨架整体旋转与收缩**，绝不破坏和弦结构。

### 3. 5px 点击防抖容差
由于数位板压感笔笔尖在屏幕上点按时容易产生几像素的轻微滑动或抖动，普通拾色器往往误判为“拖拽”，导致锚点意外位移。Colorink 内置了 **5 像素防抖阈值**：
- 在 5px 范围内的微小位移一律视为**点选**，确保稳健选色不误触；
- 超过 5px 才会进入平滑拖曳，手感扎实跟手。

### 4. 色域边界智能吸附
当你在色盘上将取色手柄拉出当前 sRGB 的有效色彩范围时，Colorink 会自动沿最短几何路径将手柄**智能吸附在有效边界上**，避免选色手柄被“卡死”在无法显示的死角。
