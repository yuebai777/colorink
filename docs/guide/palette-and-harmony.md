# 色盘、色空间与调和配色全解析

Colorink 拥有极为灵活的色彩引擎，支持 **5 种专业色彩空间模块**、**标准色轮与 LAB 环形色盘双大视图**，以及专为插画与原画设计的 **五大调和配色系统**。

---

## 1. 五大色彩空间模块（Color Space Modules）

Colorink 并不局限于单一的传统拾色器，它支持 5 种不同的数学色空间模型：

| 模块名称 | 色彩模型 | 特点与适用场景 |
| :--- | :--- | :--- |
| **HSV (默认)** | 色相-饱和度-明度 | 最经典的数字绘画色彩空间，色轮内搭配标准三角形或方形取色区。 |
| **VHSV** | 感知饱和度-明度 | 对传统 HSV 的饱和度与明度做视觉感知修正，暗部与纯色过渡更加平滑自然。 |
| **HLS** | 色相-亮度-饱和度 | 采用双锥体色彩模型，纯白与纯黑分别位于切片顶点与底边，中间为纯色饱和度。 |
| **RGB** | 红-绿-蓝正交切片 | 以 RGB 三原色立方体截面为基础，直观调节红绿蓝通道比重。 |
| **LCH (OKLCh)** | 感知明度-色度-色相 | 基于现代 OKLCh 感知均匀色彩空间，色度与明度严格线性贴合人眼，是高端概念设计调色的首选。 |

### 如何切换色彩模块？
1. **直接点击图标**：色盘右上角提供浮动的模块切换按钮；
2. **在设置中选择**：进入 **设置 → 取色器 → 色彩空间模块** 下拉菜单切换。

## 2. 色轮与 LAB 环形色盘双视图

你可以随时在常规色相环与高精度 LAB 环形色盘之间穿梭：

### 快速切换方式
- **局部悬停快捷键（推荐）**：鼠标光标移动到色盘上方时，轻按键盘 **`Space`（空格键）**，即可瞬间在色相环与 LAB 色盘间往返；
- **全局快捷键**：在任意窗口位置按下 **`Ctrl + Alt + L`**；
- **色盘浮动按钮**：点击色盘与前景色块之间的 **`⊙/△` 视图切换按钮**。

### 色盘形态与镜像定制
- **水平镜像色环**：进入 **设置 → 取色器 → 水平镜像色环**。开启后，色环左右对调翻转，方便画师按照个人习惯排布“左冷右暖”或“左暖右冷”；
- **圆形（Disc）与方形（Square）切换**：LAB 色盘支持平滑圆形切片与方形色阶切片两种几何外观；
- **灰白棋盘格背景**：可自由开关 LAB 色盘底部的棋盘格透明度指示底纹；
- **Ringless 极简切片模式**：如果你希望最大限度精简界面，可在设置中开启“隐藏色环放大切片”，色相环将被隐去，取色切片将紧凑横向拉伸撑满窗口。

## 3. 五大调和配色系统（Harmony）

开启 LAB 色盘上的调和模式后，色盘上会自动衍生出一组符合经典色彩理论的调和配色骨架点：

```
           [基准主点]
             /    \
            /      \
      [副点 1]    [副点 2]
```

| 配色模式 | 调和关系与用法建议 |
| :--- | :--- |
| **互补色 (Complementary)** | 180° 对角色彩。冷暖对比强烈，适合主角高光与背景对比拉扯。 |
| **补色分割 (Split-Complementary)** | 由基准色和互补色两侧各偏转一定角度的两点构成（Y 形），相比单一互补色更具层次与灵动感。 |
| **类似色 (Analogous)** | 色相环上相隔小角度的邻近色彩，画面色调高度统一和谐，适合绘制特定时间（黄昏/清晨）或单一氛围插画。 |
| **三色调和 (Triadic)** | 等边三角形（相隔 120°）三色组合，色彩丰富鲜明且视觉能量平衡。 |
| **矩形 (Rectangle)** | 90° 正方形/矩形方阵，提供两组互补色，适合复杂群像与多人画面配色。 |

### 调和点精细交互指南
- **点击副点选色**：你可以直接用笔或鼠标单击色盘上的任意副调和点，该点色彩立即被选定为当前前景色；
- **拖动主锚点**：主色位移时，全组调和点自动以严密的几何约束联动跟随；
- **拖动副锚点**：拖动副点时，Colorink 通过逆向映射实时联动整组骨架进行旋转或收放；
- **数位板压感笔 5px 防抖保护**：内置 5 像素微动防抖算法，手绘笔尖在屏幕上点触时，微小手抖绝对不会被误判为拖拽，手感稳定利落；
- **色域边界智能吸附**：当拖动手柄越出当前 sRGB 的有效显示范围时，Colorink 会自动沿最短几何路径将锚点吸附在有效边界上，不会卡死在边界外。

## 4. 双色槽与透明色（Preview Swatches）

主界面左上角（或右上角）放置着前景色（FG）、背景色（BG）与透明色控制块：

- **左键单击**：在编辑“前景色”与编辑“背景色”之间切换编辑目标；
- **右键色块呼出格式复制菜单**：在前景或背景色块上**右键单击**，可直接一键复制多种专业格式：
  - **HEX**：`#RRGGBB`
  - **RGB**：`rgb(r, g, b)`
  - **HSL**：`hsl(h, s%, l%)`
  - **OKLCh**：`oklch(L C h)`（高精度色彩空间标准）
  - **LAB**：`lab(L% a b)`
- **透明色胶囊按钮（棋盘格图标）**：点击将当前色槽切换为透明色，在连接 CSP 时可无缝触发绘图软件的透明色橡皮擦模式。
