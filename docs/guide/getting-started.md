# 快速上手

欢迎使用 **Colorink**！这是一套专为 Windows 平台绘画与插画工作流深度打磨的桌面取色与调色工具。本文将带你在 3 分钟内完成安装与基础操作。

---

## 1. 下载与运行

前往 GitHub 官方 Release 页面下载最新发布版本：
👉 **[下载最新版 Colorink 发布包](https://github.com/yuebai777/colorink/releases/latest)**

### 版本选择
- **`Colorink.exe`（单文件推荐）**：单文件绿色版，体积适中，下载到任意目录（如桌面或绘画工具包目录）双击即可运行，无需解压，不写外部垃圾文件。
- **`Colorink-Onedir.zip`（便携目录版）**：解压为一个文件夹，适合排查杀毒软件拦截或运行环境依赖问题。

> [!TIP] 环境要求
> - 操作系统：Windows 10 或更高版本（64 位系统）
> - **无需安装 Python**，也不需要任何额外运行库（发布包中已内置全部依赖）。

---

## 2. 首次运行安全提示

由于 Colorink 为开源独立软件，且尚未购买昂贵的微软商业代码签名证书，在部分 Windows 电脑上首次双击运行时，系统可能弹出蓝色提示窗口：
> **“Windows 已保护你的电脑” (Windows SmartScreen)**

**解决办法**：
1. 点击窗口中的 **“更多信息”**；
2. 随后右下角会出现 **“仍要运行”** 按钮，点击即可正常启动。
3. 本软件源码完全开放于 GitHub，请放心使用。

---

## 3. 主界面布局导览

启动 Colorink 后，主窗口默认显示以下核心区域：

```
+-----------------------------------------------------------+
| [≡ 菜单]              Colorink v1.8.x             [⚙ 设置] |
+-----------------------------------------------------------+
|                                                           |
|             [ 色环 / LAB 环形色盘区域 ]                     |
|                                                           |
+-----------------------------------------------------------+
| [前景色块] [背景色块]  [透明色胶囊]   [互换] [复制] [视图切换] |
+-----------------------------------------------------------+
| [滑块组 (可折叠标签页 Tabs)]                              |
|  - R / G / B 或 H / S / V 或 L / A / B 数值滑条           |
+-----------------------------------------------------------+
| [取色历史面板 (格子色板)]                                  |
+-----------------------------------------------------------+
```

1. **色盘工作区**：直观拾取色相与明度/饱和度，支持标准色相环与环形 LAB 调和色盘无缝切换；
2. **双色槽控制条**：
   - **前景色 / 背景色**：方便实时对照主副色，一键互换或复制；
   - **透明色标记（棋盘格胶囊）**：点击标记当前为透明色（可同步给 CSP 等支持透明橡皮擦模式的画图软件）；
3. **滑块与数值面板**：提供 RGB、HSV、HSL、CIELAB、OKLab、OKLCh 等多种多色域精确微调；
4. **取色历史面板**：自动记录你每次从屏幕或外部软件同步的颜色，支持点击重新选用与置顶；
5. **右上角设置齿轮**：进入设置面板，配置绘画软件连接、快捷键、界面不透明度等。

## 4. 默认快捷键速查表

Colorink 的快捷键经过精心挑选，默认采用 `Ctrl + Alt` 组合键，极大地规避了与 Photoshop、CSP、SAI2 等绘画软件内部快捷键的冲突：

| 操作功能 | 默认全局快捷键 | 简要说明 |
| :--- | :--- | :--- |
| **全屏取前景色** | `Ctrl + Alt + Q` | 呼出全屏放大镜，鼠标点击任意像素即可取色并同步 |
| **切换跟随鼠标** | `Ctrl + Alt + J` | 让 Colorink 窗口随鼠标光标移动，松开固定 |
| **显示 / 隐藏主窗口** | `Ctrl + Alt + Y` | 一键将窗口隐藏到托盘或重新唤出 |
| **显示 / 隐藏标题栏** | `Ctrl + Alt + K` | 切换为无边框极简悬浮模式 |
| **切换灰度滤镜** | `Ctrl + Alt + D` | 快速开关黑白灰度，检查画布素描明度关系 |
| **切换 LAB / 色环（悬停）** | `Space`（空格） | 鼠标位于色盘区域时，按空格瞬间切换色环与 LAB |
| **切换 LAB / 色环（全局）** | `Ctrl + Alt + L` | 任意位置全局快速切换当前色盘视图 |

> [!NOTE] 快捷键与按键映射
> 在 **设置 → 快捷键** 中，你不仅可以修改键盘组合，还可以把它们绑定到**鼠标侧键、中键，甚至是数位板压感笔的按键**上！
> 全局鼠标热键不会拦截点击，绘画软件依然能正常接收画笔操作。
