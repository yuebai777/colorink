# 快速上手指南

欢迎使用 **Colorink**！这是一套专为 Windows 平台绘画与插画工作流深度打造的桌面取色与调色辅助工具。本文将带你在 3 分钟内完成安装、初识界面与掌握核心快捷键。

---

## 1. 下载与运行

前往 GitHub Releases 官方下载页：
👉 **[下载最新版 Colorink](https://github.com/yuebai777/colorink/releases/latest)**

### 版本选择指南
- **`Colorink.exe`（单文件推荐 ⭐⭐⭐⭐⭐）**：单个可执行文件，下载到任意目录（如桌面、绘画工具包文件夹）双击直接运行，无需解压，不写任何系统垃圾；
- **`Colorink-Onedir.zip`（便携目录版）**：解压为一个独立文件夹，所有依赖 `.dll` 明文可见，适合在对单文件打包敏感的杀毒软件环境下使用。

> [!NOTE] 系统环境要求
> - 操作系统：Windows 10 / Windows 11（64 位系统）
> - **无需安装 Python**，也不需要手动配置任何环境，所有依赖已完整内置。

## 2. 首次运行安全提示（Windows SmartScreen）

由于 Colorink 为个人独立开源软件，未购买昂贵的微软商业代码签名证书，在部分电脑首次双击时，Windows 可能弹出蓝色提示窗：
> **“Windows 已保护你的电脑”**

**处理方法**：
1. 点击窗口中的文字 **“更多信息”**；
2. 随后右下角将出现 **“仍要运行”** 按钮，点击即可正常启动。
3. Colorink 100% 开源透明，源码公开于 GitHub，请放心使用。

---

## 3. 主界面结构全景导览

启动 Colorink 后，主界面直观呈现为以下功能区域：

```
+-----------------------------------------------------------+
| [≡ 菜单]              Colorink v1.8.x             [⚙ 设置] |
+-----------------------------------------------------------+
|                                                           |
|             [ 色轮 / LAB 环形色盘工作区 ]                   |
|                                                           |
+-----------------------------------------------------------+
| [前景色] [背景色] [透明胶囊]      [⊙/△ 切换]  [模式切换按钮] |
+-----------------------------------------------------------+
| [滑块组 (可拖拽重排 / 可分页签叠放 Tabs)]                  |
|  - R / G / B 或 H / S / V 或 L / A / B 滑条与数值框       |
+-----------------------------------------------------------+
| [取色历史面板 (去重置顶 / 支持右键复制色码)]                |
+-----------------------------------------------------------+
```

1. **色盘工作区**：直观拾取色相与明度/饱和度，支持 5 种色彩空间模块（HSV / VHSV / HLS / RGB / LCH）与双大视图无缝切换；
2. **双色槽与透明色**：
   - **前景色 (FG) / 背景色 (BG)**：单击切换编辑目标，**右键单击弹出 HEX / RGB / HSL / OKLCh / LAB 复制菜单**；
   - **透明色胶囊（棋盘格图标）**：一键切换透明色，同步至 CSP 等支持透明橡皮擦模式的画画软件；
3. **滑块与数值面板**：精确输入与微调各色彩空间数值，开启抓手后可自由拖拽重排或合并为分页签；
4. **取色历史面板**：自动记录屏幕取色与外部软件同步色彩，左键点击直接复用，右键支持复制色码；
5. **右上角设置齿轮**：进入设置面板，配置快捷键、软件连接、界面半透明度等。

## 4. 默认快捷键速查表

Colorink 的默认快捷键均采用 `Ctrl + Alt` 组合，极大地规避了与 Photoshop、CSP、SAI2 等绘画软件内部工具快捷键的冲突：

| 操作功能 | 默认热键 | 作用范围 | 使用说明 |
| :--- | :--- | :--- | :--- |
| **全屏取色放大镜** | `Ctrl + Alt + Q` | 全局 | 随时呼出取色视窗，带 Alt 冻结、滚轮缩放、Shift 锁定轴等功能 |
| **切换跟随鼠标** | `Ctrl + Alt + J` | 全局 | 让 Colorink 窗口移动到光标位置，便于随笔调色 |
| **显示 / 隐藏窗口** | `Ctrl + Alt + Y` | 全局 | 一键隐藏到系统托盘或重新唤出 |
| **显示 / 隐藏标题栏** | `Ctrl + Alt + K` | 全局 | 隐去窗口标题栏与外框，进入极简悬浮模式 |
| **切换全屏灰度滤镜** | `Ctrl + Alt + D` | 全局 | 一键把屏幕（或画画数位屏）变为黑白视图，检查素描明度关系 |
| **色盘视图切换（悬停）** | `Space`（空格） | 局部悬停 | 鼠标光标位于色盘区域时，按空格瞬间切换色相环与 LAB 色盘 |
| **色盘视图切换（全局）** | `Ctrl + Alt + L` | 全局 | 任意位置全局切换色相环与 LAB 色盘 |

> [!TIP] 支持绑定鼠标侧键与数位板笔按键
> 在 **设置 → 快捷键** 中，所有热键均可自由修改，并支持直接绑定到**鼠标侧键、滚轮中键、甚至数位板压感笔的按键**上！
> 作为全局热键时，鼠标点击不会被拦截，绘画软件依然能正常接收画笔操作。

> [!TIP] 用不上的快捷键可以解绑
> 两种方式都能把快捷键设为「无」：点每一行热键右侧的 **无** 按钮，或者点热键按钮进入录制后按 **Delete**（Backspace 同样可以）。
> 解绑后该键位立刻停止响应、重新交还给绘画软件，按钮显示「未绑定」，重启后依然保持；需要时再点按钮录制一个新键位即可。
