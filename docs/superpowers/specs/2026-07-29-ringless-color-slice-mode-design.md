# 无色相环放大切片模式

## 目标

为 Colorink 增加一种色图显示模式：隐藏外围色相环，保留并放大当前 HSV、HLS、LCH 模块各自已有的色彩切片。该模式参考 Procreate 的空间占比，把主要面积交给二维切片，并把前景色 / 背景色改为顶部并排的小号圆角长方形。

本功能不是新的色彩空间模块，也不改变三种模块的颜色计算、滑块组合或同步数据。

## 当前行为

- HSV 模块使用 `hsv-square`，HLS 模块使用 `hls-triangle`，LCH 模块使用 `oklch-slice`。
- `ColorWheel.paintEvent()` 先绘制外围色相环，再按当前模块绘制内部切片和指示器。
- 前景色 / 背景色由浮动的 `ColorPreviewBox` 以两个重叠圆形显示，位置可选左上角或左下角。
- 模块切换按钮和色轮 / LAB 切换按钮浮动在视觉区右下角。

## 批准行为

- 该功能是新增的可选显示模式，不替换、不删除任何现有模式或设置。
- 设置中提供“完整色相环”和“仅色彩切片”两种显示方式，默认继续使用完整色相环。
- 仅色彩切片模式只跳过外围色相环及其色相指示器；当前模块的切片、内部指示器、拖动和颜色转换保持不变。
- HSV 继续显示 `hsv-square`，HLS 继续显示 `hls-triangle`，LCH 继续显示 `oklch-slice`。
- 切片使用去掉色相环后释放的空间，并在不改变原始几何比例、不裁切边界的前提下尽量填满视觉区。
- HLS 三角形与 LCH 切片按各自实际可见外框居中，而不是把内部几何锚点或透明缓存画布误当作可见外框中心。HLS 锚点相对可用区中心左移 `r/4`；OKLCh 可见 gamut 以可用区中心作为锚点。内部 RGB slice 保留其既有独立几何。
- 前景色 / 背景色显示为两个等宽、等高、互不重叠的圆角长方形。当前槽使用现有蓝色强调描边，非当前槽使用中性细描边。
- 双色模块内部始终按前景色在前、背景色在后的顺序排列；左右设置只移动整个模块，不镜像两个色块的内部顺序。
- 双色模块和当前页可见的现有切换按钮共用视觉区顶部的窄控制带。双色模块靠右时按钮靠左；双色模块靠左时按钮靠右。
- 双色模块位置可在设置中独立选择左侧或右侧，默认靠右以匹配批准的 Procreate 参考方向。
- 点击色块选择前景色或背景色，双击交换两种颜色，右键复制颜色值；这些语义与当前 `ColorPreviewBox` 一致。

## 兼容性不变量

- 应用首次启动及没有新配置字段的既有安装继续进入当前完整色相环模式。
- 当前 HSV 完整色环、HLS 完整色环和 LCH 完整色环表现全部保留；新增模式只改变用户明确启用后的绘制与布局。
- 当前色轮 / LAB 切换继续存在，LAB / OKLab 色图算法、取色语义及 LAB 亮度滑条行为不变。
- 无环模式关闭时，当前重叠圆形前景色 / 背景色预览继续用于完整色相环和 LAB 布局；无环模式开启时，色轮页与 LAB / OKLab 页都使用顶部并排长方形预览。
- 当前模块切换按钮、色轮 / LAB 切换按钮及其快捷操作继续存在；无环模式开启时，色轮页和 LAB / OKLab 页的可见切换按钮都进入顶部控制带并位于双色模块对侧。
- 当前 `previewBoxPosition` 的左上角 / 左下角选项及已有持久化值继续有效。
- 用户关闭新增模式后，界面必须恢复到启用前的完整色相环、重叠圆形预览和右下角按钮布局，不丢失颜色、活动色槽、模块或窗口状态。

## 布局与尺寸

以下尺寸以 `uiScale=100%` 为基准，并随现有界面缩放等比例变化：

- 顶部控制带高度约 39 px，不增加第三个切换按钮。
- 顶部控制带同时适用于色轮页和 LAB / OKLab 页。LAB 页的二维色图与竖向亮度条整体避开控制带，不允许控件覆盖色图或亮度条。
- 单个前景色 / 背景色色块约 43 × 24 px，圆角约 4 px，两个色块间距约 5 px。
- 现有切换按钮继续使用约 28 × 28 px 的点击区域和既有图标 / 提示文本；色轮页显示模块与页面切换按钮，LAB 页只显示页面切换按钮。
- 切片区域四周保留约 7 px 的视觉边距。
- HSV 方形使用切片区域内可容纳的最大正方形。
- HLS 三角形保持 `get_triangle_vertices()` 当前朝向和宽高关系，在切片区域内按宽、高双重约束最大化。
- HLS 三角形的实际横向边界为 `[cx - 0.5r, cx + r]`，几何锚点必须取 `availableCenterX - r/4`，使边界中心与可用区中心重合。
- LCH 切片保留当前中性轴、sRGB 色域边界曲线和边界外透明区。`_oklch_scale_for_hue()` 将当前色相的最大边界色度映射到 `r` 像素，因此实际可见横向边界为 `[cx - 0.5r, cx + 0.5r]`，而不是旧的 2r 透明缓存画布。几何锚点必须取 `availableCenterX`，半径按 `min(availableWidth, availableHeight / 1.732)` 最大化，缓存画布和 OKLCh 命中范围收紧到同一可见横向边界。

绘制、内部指示器和鼠标命中必须读取同一份几何结果，不能分别推导尺寸，否则放大后会出现指示器与拖动位置不一致。

## 组件设计

`MainWindow` 负责读取模式与左右位置设置，并在几何更新时统一切换以下表现：

1. `ColorWheel` 接收是否显示色相环以及顶部控制带占用的空间。
2. `ColorWheel` 为三种现有切片计算共享的可用矩形；完整色相环模式继续走当前几何，避免回归。
3. `ColorPreviewBox` 增加并排长方形表现形式，复用现有前景色、背景色、当前槽和鼠标交互状态。
4. `PaneWithModeButton` 在仅色彩切片模式下把当前页可见按钮锚定到顶部控制带的另一侧；完整色相环模式仍锚定右下角。色轮页保留模块与页面切换按钮，LAB 页只显示页面切换按钮。
5. LAB / OKLab 视觉页保留当前色图和亮度条逻辑，但在无环模式下复用顶部控制带、长方形双色预览和对侧按钮，并通过布局上边距为整个控制带留出空间。

`RinglessLayout.wheel_enabled` 表示色轮切片当前是否进入无环绘制，仅在配置启用且色轮页可见时为真；`controls_enabled` 表示统一顶部控制带是否启用，只取决于配置开关，因此在色轮页与 LAB / OKLab 页都保持为真。

不复制前景色 / 背景色业务状态。两种外观都必须读取 `MainWindow` 已有的 `active_slot`、`fg_color`、`bg_color` 和 source-space 跟踪数据。

## 设置与持久化

新增两个配置字段：

- `hideHueRing: false`：是否启用仅色彩切片模式。
- `ringlessControlsSide: "right"`：仅色彩切片模式下双色模块所在侧，值为 `left` 或 `right`。

设置侧栏在色彩空间模块附近增加“隐藏色相环并放大切片”复选框；启用后显示“无色环双色位置”下拉框，选项为“左侧”和“右侧”。现有 `previewBoxPosition` 继续管理无环模式关闭时完整色相环 / LAB 布局的左上角或左下角，不改变已有配置语义。

保存后立即刷新色图缓存、控制带位置、预览外观和窗口几何。现有配置文件通过默认值合并获得新字段，不需要迁移旧值。

## 数据流

设置侧栏保存配置 -> `MainWindow.on_settings_saved()` 重新加载配置 -> 更新 `ColorWheel` 显示方式与缓存 -> `update_geometries()` 计算控制带和切片区域 -> 当前 HSV / HLS / LCH 绘制与命中逻辑使用新的共享几何 -> `ColorPreviewBox` 与当前页可见切换按钮更新外观及左右位置。

颜色变化仍沿用现有路径：切片或滑块交互 -> `MainWindow.update_ui_colors()` -> 当前槽颜色、滑块、历史和同步后端更新。显示模式不进入颜色数据流。

## 边界处理

- 未知的 `ringlessControlsSide` 值按 `right` 处理。
- 视觉区尺寸不足时优先保持切片原始比例和按钮点击区域，不拉伸 HSV 方形、HLS 三角形或 LCH 色域边界。
- 切换模块、切换色轮 / LAB、调整窗口大小、改变 UI 缩放或跨 DPI 屏幕移动后都重新计算几何、顶部控制带布局并失效对应切片缓存。
- 仅色彩切片模式不强制显示被用户关闭的滑块组；色相继续通过当前模块已有的 H / h 滑块或外部颜色同步改变。

## 验证

- 分别在 HSV、HLS、LCH 模块启用仅色彩切片模式，确认外围色相环和色相环指示器消失，现有切片与内部指示器仍可见。
- 确认 HLS 实际三角形边界与 OKLCh 渲染后的非透明 gamut 边界分别在可用区内水平居中，左右留白差不超过 1 px，且绘制、指示器、命中和拖动使用同一修正后锚点。不得以包含整块透明右半区的缓存画布代替可见边界进行断言。
- 在多种窗口宽度、UI 缩放和 DPI 下确认 HSV 方形不变形、HLS 三角形不裁切、LCH 色域边界与透明区正确。
- 对三种切片的边缘、中心和当前指示器位置执行点击与拖动，确认取色结果和完整色相环模式下相同坐标语义一致。
- 切换前景色 / 背景色，确认两个圆角长方形的颜色和活动描边正确；双击交换与右键复制保持可用。
- 将双色模块分别设置在左侧和右侧，确认两个切换按钮自动移动到相反侧且没有重叠。
- 切换 HSV / HLS / LCH 模块，确认按钮标签、切片类型、滑块组和颜色状态同步更新。
- 切换到 LAB / OKLab 视觉页，确认长方形双色预览与页面切换按钮继续位于顶部控制带两侧，色图与竖向亮度条位于控制带下方；返回色轮后无色相环模式及位置设置仍保持。
- 关闭该模式，确认完整色相环、重叠圆形预览和右下角按钮恢复为当前行为。
- 在关闭新增模式时逐一回归 HSV、HLS、LCH、LAB 和 OKLab 当前显示路径，确认没有控件或交互被删除。
- 重启应用，确认显示模式和左右位置从配置恢复。
- 运行窗口自适应高度、跨 DPI、颜色同步和色槽 source-space 相关回归测试。

## 非目标

- 不新增第四种色彩空间或新的切片算法。
- 不把 Procreate 的三条滑条、深色主题或其他界面元素移植到 Colorink。
- 不改变 HSV、HLS、OKLCh 转换、LCH 色域边界计算、LAB / OKLab 色图算法或同步协议。
- 不删除完整色相环模式，也不改变其默认行为。
- 不重构与本显示模式无关的设置、滑块或颜色历史功能。
