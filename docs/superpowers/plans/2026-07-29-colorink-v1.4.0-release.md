# Colorink v1.4.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare, verify, commit, and publish Colorink v1.4.0 without losing functionality from the current worktree.

**Architecture:** Keep the existing PyQt6 application and PyInstaller specs. Change only release metadata, first-run defaults, release documentation, and focused tests; validate the existing feature changes through imports, tests, and both build modes.

**Tech Stack:** Python 3.14, PyQt6, PyInstaller, pytest, Git, GitHub CLI.

## Global Constraints

- Target version is `v1.4.0`; application version is `1.4.0`; Windows file/product version is `1.4.0.0`.
- Existing user config values must never be overwritten; only absent keys receive defaults.
- Do not commit `build/`, `dist/`, `.reasonix/`, `err.log`, `stderr.log`, caches, or generated binaries outside the release asset.
- Preserve all current user changes; never reset or checkout unrelated files.
- Push only to the existing `origin` remote and never force-push.
