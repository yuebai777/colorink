# CLIP STUDIO PAINT (CSP) 同步指南

CLIP STUDIO PAINT 是 Colorink 深度打磨与重点优化的目标软件之一。对于 CSP 用户，我们强烈推荐使用官方原生兼容的 **Companion（伴侣）模式**。

---

## 模式推荐：Companion 手机伴侣模式（首选 ⭐⭐⭐⭐⭐）

### 为什么强烈推荐 Companion 模式？
1. **官方原生 TCP 协议**：利用 CSP 自带的“连接智能手机作为掌上助手”协议通讯，完全不需要读取或篡改 CSP 内存；
2. **免除版本升级困扰**：无论 CSP 更新到 2.x、3.x 还是最新的 5.x，协议始终兼容，彻底告别“软件一更新内存地址就失效”的麻烦；
3. **支持透明色**：在 Colorink 上点击透明色胶囊，CSP 画笔会立即无缝切换到透明橡皮擦模式；
4. **超低延迟（约 5.5ms~7.5ms）**：采用非阻塞极速通信，取色即落笔。

---

### 配置步骤（30 秒完成）

#### 第一步：在 CSP 中打开配对二维码
1. 打开 CLIP STUDIO PAINT 电脑端；
2. 在 CSP 顶部命令栏或顶部菜单栏找到 **“连接智能手机”** 图标（手机形状图标），点击它；
3. 此时 CSP 会弹出一个包含二维码的配对窗口。

#### 第二步：在 Colorink 中建立连接
1. 打开 Colorink，点击右上角 **设置（齿轮） → 同步**；
2. 在同步模式中选择 **CSP (Companion)**；
3. 点击旁边的 **【自动扫描屏幕二维码】** 按钮；
4. Colorink 会在瞬间自动识别屏幕上 CSP 窗口里的二维码，并立即建立双向握手！
5. 看到状态变为绿色的 **“已连接”** 后，即可关闭 CSP 的二维码弹窗，开始尽情画画！

---

### 如果自动扫码失败，如何手动连接？
如果由于屏幕缩放、窗口遮挡或多显示器导致自动扫码未触发，可以采用 100% 成功的手动方式：
1. 在 CSP 弹出的二维码窗口下方，点击 **“无法扫描二维码时”**（或类似的帮助文字）；
2. CSP 会显示一串本地局域网连接地址（例如 `http://192.168.x.x:xxxxx` 或类似代码）；
3. 复制该地址，粘贴到 Colorink 设置页的 **“手动连接 URL”** 输入框中，点击 **【连接】** 即可。

---

## 备用方案：CSP 内存同步模式

针对部分未开启网络权限或特殊老版本的 CSP（如 4.x / 5.0），Colorink 也内置了内存定位引擎：
- 进入 **设置 → 同步**，切换到 **CSP (Memory 内存模式)**；
- 确保 CSP 正在运行并且当前有打开的画布；
- Colorink 会自动定位主副色槽内存指针并自愈恢复。

> [!WARNING] 注意事项
> 如果你的 CSP 已更新到 **5.1 或更高版本**，请务必使用 **Companion 模式**，内存模式可能因官方重新编译的二进制偏移而无法定位。

## 常见排错
- **问：点击自动扫码提示没找到二维码？**  
  答：请确保 CSP 的二维码弹窗完整显示在电脑屏幕上（没有被其他网页或全屏游戏挡住）。
- **问：取色后画笔颜色变了，但想切换透明色怎么做？**  
  答：在 Colorink 色盘下方点击棋盘格的“透明色”按钮，CSP 会立即将当前工具切换为透明色。再次选取任意颜色，即可恢复正常彩色画笔。
