# CLIP STUDIO PAINT (CSP) 同步指南

CLIP STUDIO PAINT (CSP) 是 Colorink 深度适配的核心绘画软件。推荐使用官方原生协议的 **Companion（伴侣）模式**。

---

## 模式一：Companion 伴侣模式（强烈推荐 ⭐⭐⭐⭐⭐）

### 为什么首选 Companion 模式？
- **跨版本终身兼容**：使用 CSP 官方内置的“智能手机助手”局域网 TCP 协议通信，完全不受 CSP 升级版本（2.x / 3.x / 4.x / 5.x）影响；
- **全能力支持**：不仅支持前景色与背景色，还完美支持**透明色（透明笔刷橡皮擦）**；
- **自动持久化静默重连**：首次配对成功后，配置会自动保存，之后每次打开软件都会自动尝试重连。

---

### 配对操作三步法（30 秒完成）

#### 第一步：在 CSP 中打开连接二维码
1. 打开电脑上的 CLIP STUDIO PAINT；
2. 在顶部命令栏或菜单中找到 **“连接智能手机”** 图标（手机形状），点击呼出配对窗口；
3. 屏幕上将显示包含配对二维码的弹窗。

#### 第二步：在 Colorink 中一键自动扫码
1. 打开 Colorink，进入 **设置 → 同步**；
2. 在目标软件中选择 **CSP (Companion)**；
3. 点击 **【自动扫描屏幕二维码】** 按钮；
4. Colorink 会在瞬间自动识别屏幕上的二维码并完成双向配对握手；
5. 设置页状态变为绿色的 **“已连接”** 后，即可关闭 CSP 的二维码弹窗，开始画画！

---

### 自动扫码失败时的手动备用连接方法
如果因为多显示器、屏幕超高缩放比例或窗口层叠导致自动扫码未能识别：
1. 在 CSP 的二维码弹窗下方，点击 **“无法扫描二维码时”**（或“显示连接代码”）；
2. CSP 界面会显示一串本地局域网地址（例如 `http://192.168.x.x:54321?...`）；
3. 复制整串地址，粘贴到 Colorink 设置中的 **“手动连接 URL”** 输入框中；
4. 点击旁边的 **【连接】** 按钮即可成功连接。

---

## 模式二：CSP 内存同步模式（旧版备用）

针对无法连接本地局域网网络的老旧电脑，Colorink 保留了基于内存扫描的同步模式：

1. 进入 **设置 → 同步**，选择 **CSP (Memory 内存模式)**；
2. 在版本下拉菜单中选择对应版本（如 `csp4.x` 或 `csp5.x`）；
3. 确保 CSP 已经打开一张画布，Colorink 会自动挂钩内存并同步颜色。

> [!WARNING] 关键版本提示
> - **CSP 5.1+ 已彻底移除内存同步支持**：官方在 5.1 版本中重构了底层色彩结构，因此 **CSP 5.1 及更高版本必须使用 Companion 模式**；
> - 内存模式仅支持主色同步，不支持背景色与透明色。
