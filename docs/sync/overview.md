# 绘画软件同步概览

Colorink 的核心使命之一，就是让画师在外部调色器选好的色彩**以不可感知的超低延迟直接注入你正在使用的绘画软件**中。

你不需要一次次在画画软件里按快捷键弹出笨重的小窗口吸色，也不用手动复制十六进制色码。只要在 Colorink 里挑好颜色，画笔颜色已经就位。

---

## 2. 核心同步特性

### 1. 前景色与背景色独立通道
Colorink 支持同时维护前景色与背景色两个色槽：
- 在主界面可以一键对调（Swap）、复制对比；
- 在连接 Photoshop 或 CSP 时，可以分别更新主笔刷色与副色，甚至可以把当前取色指定填入背景色槽。

### 2. 原创“透明色”透传机制
很多插画师在 CSP 中习惯使用**“透明色”（即透明画笔/橡皮擦模式）**来做擦除或削边造型：
- Colorink 界面提供了专门的**透明色胶囊按钮（棋盘格图标）**；
- 在 Companion 模式下点击该按钮，CSP 会立即自动切换至透明色槽，无需你回画布上按 `C` 键或切换橡皮擦工具，画画节奏不被打断。

### 3. 选色即画
选好颜色后直接在画布下笔，Colorink 会自动实时更新绘画软件的当前画笔颜色，无需额外等待。
