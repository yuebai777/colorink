# 绘画软件同步总览

Colorink 拥有强大的外部色彩同步中枢，可将你在调色盘中拾取或微调的色彩，以毫秒级速度直接推送到目标绘画软件中。

---

## 2. 核心功能与工作流机制

### 1. 自动识别前台软件（Auto Mode，强烈推荐）
在 **设置 → 同步 → 目标软件** 中选择 **【自动识别】**：
- 当你在 CSP 画画时，Colorink 自动连通 CSP；
- 当你切到 Photoshop 时，Colorink 毫秒级自动切换为 Photoshop CEP 桥；
- 切到 SAI 2 时同理，多软件协同作业再也不需要手动来回切换设置！

### 2. 前景色与背景色独立双向通道
- **Colorink → 软件**：在 Colorink 界面点击前景色或背景色块，调色动作只会影响当前选中的色槽；
- **软件 → Colorink**：在 Photoshop 或 CSP 中用吸管工具吸取画布颜色，Colorink 会自动感应并将颜色回填至对应色槽，同时记入历史色板。

### 3. 原生“透明色”透传机制
在 CSP 中许多画师习惯用透明色来当做带有当前笔刷笔触质感的橡皮擦使用：
- 点击 Colorink 界面上的**透明色胶囊按钮（棋盘格图标）**；
- CSP 会立即切换为透明色槽；在 Colorink 再次选择任意色彩，CSP 立即无缝恢复为正常画笔彩色。

### 4. 实时状态灯与诊断反馈
在 **设置 → 同步** 底部，Colorink 提供了精准的状态监测：
- 🟢 **绿色**：已成功连接，当前下笔即可生效；
- 🔴 **红色**：未检测到运行中的目标绘图软件或连接断开；
- 点击 **【复制诊断信息】**：可一键将当前软件版本、系统环境与详细同步错误日志复制到剪贴板，方便提交反馈。
