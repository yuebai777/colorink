# PaintTool SAI2 / 优动漫 PAINT (UDM) 同步指南

Colorink 针对广受画师喜爱的 **PaintTool SAI 2** 以及国行版本的 **优动漫 PAINT (UDM Paint Pro / EX)** 开发了专用的内存级画笔色彩同步引擎与智能界面重绘机制。

---

## 1. 原理与特性

- **内存级画笔颜色直接注入**：直接锁定绘图软件内部当前激活的画笔颜色数据，调色瞬间生效；
- **智能色块刷新机制 (针对 SAI2)**：解决了传统第三方工具在修改 SAI 2 颜色后，SAI 2 界面左侧的小颜色色格未能及时刷新的视觉滞后问题；
- **SAI2 色轮跟随（新增）**：写色时同步更新 SAI 自己的颜色面板状态，SAI 的**色轮（色环与内部方块的画面、色环标记、方块取色点）与滑块轨道的渐变**会跟着变色（详见下方「面板模式」）；滑块 thumb 与右侧数值读数**不会**跟着变，原因见下；
- **无需安装任何额外插件**：开箱即用，自动寻址进程。

---

## 2. PaintTool SAI 2 连接与使用步骤

### 第一步：准备 SAI 2
1. 启动 PaintTool SAI 2（请确保为 64 位版本）；
2. **新建或打开一张画布**（SAI 2 在没有打开任何画布时，画笔颜色引擎处于休眠状态）；
3. 激活你想要使用的画笔工具（如铅笔、水彩、毛笔等）。

### 第二步：开启 Colorink 同步
1. 打开 Colorink，进入 **设置 → 同步**；
2. 目标软件选择 **SAI2**（或者直接选择 **自动识别**）；
3. Colorink 会在后台自动捕获 `sai2.exe` 进程，几秒钟内指示灯将显示为绿色的 **“已连接”**；
4. 此时在 Colorink 任意调节颜色，SAI 2 的画笔颜色都会实时改变。

### SAI2 色轮跟随与面板模式（设置 → 同步 → SAI2 面板模式）

Colorink 写色时会把颜色同步进 SAI 自己的颜色面板状态。**跟随的部分**：色环与内部方块的画面、色环标记、方块取色点、六条滑块轨道的渐变。**不跟随的部分**：滑块上的 thumb 三角、轨道右侧的数值读数（`186 / 049 / 222 / 288 / 078 / 087` 这些数字）。

> 为什么滑块 thumb 和数字不跟随？实测（2026-09，Preview.2024.08.14）表明：这两个东西不由 Colorink 写入的那三个色板字段驱动，而是由 SAI 自己的滑块控件状态驱动；即使强制整面板 `RedrawWindow`，字段变了、轨道渐变跟着重画，thumb 与数字仍然纹丝不动。要推动它们，只能走 SAI 自己的输入路径（模拟点击轨道 / 色板格），而现行实现刻意不发送任何点击（避免误触）。所以这是机制选择的结果，不是配置问题。

| 选项 | 说明 |
| :--- | :--- |
| **auto（默认，推荐）** | 自动识别你在 SAI 里使用的面板模式（HSV / VHSV / HSL）。识别依据有三层：SAI 自己画的滑块标签（`V` / `L`）、**用每种模式反推当前颜色并与 SAI 色槽比对**、以及面板右侧 SAI 自己写的数值读数；切模式后约 2 秒内自动跟上 |
| **vhsv / hsv / hsl** | 手动指定。适用于自动识别不了的场景（例如 SAI 当前颜色是灰阶、没有色相可判断，且面板读数也停在灰阶） |

> 说明：SAI 的三种面板模式在内存里的字段含义不同（HSL 的第 1 个字段是亮度 L，HSV/VHSV 是明度 V；VHSV 的饱和度是 SAI 特有的非线性定义）。Colorink 会按所选模式换算，因此**只要选的模式与 SAI 里实际显示的一致，色轮位置就是准的**。
> 若出现色轮位置偏差，先确认这一项与 SAI 面板右上角/底部的模式一致；改完立即生效，无需重启。

### SAI2 界面刷新（v1.8.7 起恒为全量模式）

自 v1.8.7 起，Colorink 移除了「界面刷新模式」选项（旧配置会自动迁移，无需手动处理），始终执行全量刷新：

| 动作 | 说明 |
| :--- | :--- |
| **重绘调色盘色块** | 通知 Windows 对 SAI 2 的调色盘色块区域发送局部重绘信号，色块即时刷新 |
| **刷新笔刷预览** | 同步刷新笔刷预览条，长时间作画后预览不再滞留旧色 |

> 全量刷新**不注入任何模拟鼠标点击**，不会造成「楔形起笔」；预览目标失效后会自动重新发现，无需重启 Colorink。

## 3. 优动漫 PAINT (UDM) 连接说明

优动漫 PAINT（即国内发行的 CLIP STUDIO PAINT 国行版本，进程名为 `UDMPaintPro.exe` 或 `UDMPaintEX.exe`）：

1. 打开优动漫 PAINT 并新建或打开一张画布；
2. 打开 Colorink **设置 → 同步**，目标软件选择 **UDM**（或保持 **自动识别**）；
3. Colorink 支持其 4.0 Pro 与 4.0 EX 版本，自动识别并连接画笔颜色内存；
4. 连接成功后，Colorink 中的前景色将实时同步至优动漫 PAINT 的当前画笔。

## 4. 常见排错与注意事项

### 1. 状态一直显示未连接？
- **画布是否打开**：请务必确保已经打开了一张画纸画布；
- **管理员权限一致**：如果你以管理员身份运行了 SAI2 或优动漫 PAINT，Windows 会禁止普通权限程序读取其内存。请将两者权限统一（都以普通模式运行，或都以管理员模式运行）；
- **确认 64 位程序**：SAI 2 需为 64 位版本（目前 2020 年以后的主流版本均为 64 位程序）；
- **看诊断原因**：设置页「复制诊断信息」里的 `reason` 会直接说明失败类型——
  `not_running`（没开/没画布）、`access_denied`（权限不一致）、
  `no_signature`（这个 SAI 版本还没适配，可先手动指定「SAI2 版本」）、
  `write_verify_failed`（写入被其它程序干扰）。
- **SAI2 版本**选 `auto` 时会**自动遍历所有已知签名**并选用能读到颜色槽的那个；只有全部失败才回退到固定偏移。因此通常无需手动指定，只有新版本 SAI 报 `no_signature` 时才需要反馈适配。
