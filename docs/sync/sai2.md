# PaintTool SAI2 / UDM 同步指南

Colorink 针对广受画师喜爱的 **PaintTool SAI 2** 以及同架构的 **UDM (万能绘图大师)** 开发了专用的内存级画笔色彩同步引擎与智能界面重绘机制。

---

## 1. 原理与特性

- **内存级画笔颜色注入**：直接定位 SAI 2 内部维护的当前选定笔刷颜色数据，选色即刻生效；
- **智能色块刷新机制**：解决了传统第三方工具在修改 SAI 2 颜色后，SAI 2 界面左侧的小颜色色格未能及时刷新的视觉滞后问题；
- **无需安装任何额外插件**：开箱即用，自动寻址。

---

## 2. 连接与使用步骤

### 第一步：准备 SAI 2
1. 启动 PaintTool SAI 2（请确保为 64 位版本）；
2. **新建或打开一张画布**（SAI 2 在没有打开任何画布时，画笔颜色引擎处于休眠状态）；
3. 激活你想要使用的画笔工具（如铅笔、水彩、毛笔等）。

### 第二步：开启 Colorink 同步
1. 打开 Colorink，进入 **设置 → 同步**；
2. 目标软件选择 **SAI2**（或者选择 **自动识别**）；
3. Colorink 会在后台自动捕获 `sai2.exe` 进程，几秒钟内指示灯将显示为绿色的 **“已连接”**；
4. 此时在 Colorink 任意调节颜色，SAI 2 的画笔颜色都会实时改变。

---

## 3. 三大界面刷新模式对比（重要配置）

在 **设置 → 同步 → 界面刷新模式** 中，Colorink 提供了三种刷新策略：

| 模式名称 | 运行机制 | 建议与注意事项 |
| :--- | :--- | :--- |
| **repaint (默认推荐 ⭐⭐⭐⭐⭐)** | **纯重绘事件** | 仅通知 Windows 针对 SAI 2 的调色盘色块区域发送局部重绘信号，**完全不注入任何模拟鼠标点击**，色块即时刷新且 100% 杜绝起笔误触。 |
| **full (强行点击模拟)** | **模拟画笔预览点击** | 给笔刷预览框发送一次模拟点击促使重绘。注意：SAI 会记录此次点击点，某些版本下可能导致下一笔的第一笔出现“楔形起笔”，仅在使用了特殊第三方魔改皮肤且 repaint 无效时才建议使用。 |
| **off (仅写内存)** | **关闭所有主动刷新** | 纯写内存，完全不干预 SAI 2 界面。虽然 SAI 2 界面上的小色块可能等到下笔画在画布上之后才更新视觉，但画出来的线条颜色已经生效。适合极老旧的低配电脑。 |

---

## 4. 常见排错与注意事项

### 1. 状态一直显示“未找到 SAI 2 进程”或未连接？
- **画布是否打开**：请务必确保已经打开了一张画纸画布；
- **管理员权限一致**：如果你以管理员身份运行了 SAI 2，Windows 会禁止普通权限程序读取其内存。请将两者统一（都以普通模式运行，或都以管理员模式运行）；
- **确认 64 位程序**：SAI 2 需为 64 位版本（目前 2020 年以后的主流版本均为 64 位程序）。
