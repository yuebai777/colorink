# 测试向导 · 简单使用说明

## 一、最简单：双击启动器

打开项目文件夹，双击 **`测试.bat`**：

1. 会弹出一个黑色窗口，显示菜单；
2. **直接按回车** = 一条龙测试（自动测试 → 手测打勾 → 报告）；
3. 也可以输入 `auto` / `manual` / `report` / `panel` 再回车，只做其中一件事；
4. 测完窗口会停住，按任意键关闭。

## 二、屏幕上问你问题时，怎么回答

| 按什么 | 意思 |
|---|---|
| `y` | 这条通过 ✓ |
| `n` | 这条失败 ✗ |
| `s` | 跳过（比如没有第二块屏幕） |
| `q` | 保存进度、今天先不测了 |

- 随时按 `q` 退出都**不会丢进度**，下次再跑自动接着上次继续。
- 也可以在答案后面写一句备注，比如：`y 色轮很顺`。

## 三、几个注意点

1. **跑半自动引导（guided）时**，它会自己按 F11、Ctrl+G 这些键，你**先把手从键盘鼠标上拿开**，等它问你"人工复核 y/n"再操作。
2. **自动测试里的"冒烟"检查**会启动你的 Colorink 来试它能不能开：如果你已经开着 Colorink，它会自动跳过这条并告诉你。
3. **发版那天**，用 `--release` 模式（更严格，发版项目不许跳过）：
   - 命令行：`python tools\test_wizard.py all --release`
   - 或在 测试.bat 的菜单输入 `all --release`
4. 测试结果和截图都存在项目里的 `test-reports\` 文件夹：
   - 每次的记录：`runs\` 里面
   - 报告文件：`QA-日期.md`，双击用记事本/VS Code 打开
   - 半自动截图：`shots\` 里面

## 四、不想自己跑？让 AI 助手替你跑

在会话里直接说"**跑测试**"，助手会：

1. 替你跑完自动测试（env + auto）；
2. 把结果报给你；
3. 需要你手动确认的部分，一条条问，你回答"过 / 不过 / 跳过"即可；
4. 最后给你报告结论。
